Password Authentication System

A secure authentication system built with PHP and MariaDB that demonstrates best practices for user registration, login, and password protection.

Features

- User registration and login
- Password strength validation
- Password hashing using BCrypt ("PASSWORD_DEFAULT")
- Secure password verification
- Account lockout after three failed login attempts
- MariaDB database integration

Technologies

- PHP
- HTML/CSS
- MariaDB
- XAMPP

Installation

git clone https://github.com/karw-gif/Password_auth_system.git

1. Move the project to your web server directory (e.g., "htdocs").
2. Create a MariaDB database and import the SQL file.
3. Update the database configuration.
4. Start Apache and MariaDB.
5. Open the project in your browser.

Security Features

- BCrypt password hashing
- Password strength enforcement
- Secure password verification
- Account lockout protection
